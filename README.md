# 图书管理平台

本地优先的实体书管理应用：记录藏书购入状态（已购 / 未购），豆瓣在线匹配入库并自动抓取封面，多设备自动同步。

## 在线预览

[sunyh-gi.github.io/book-catalog](https://sunyh-gi.github.io/book-catalog/)

## 主要功能

- **豆瓣匹配入库**：输入书名或 ISBN 搜索豆瓣，点候选行自动填充并下载封面
- **购入状态**：点卡片文字区切换，已购在书名末尾标绿点
- **分类浏览**：侧栏按题材 / 丛书 / 作者自动归类并计数，题材可增删改
- **多设备同步**：改动后约 4 秒自动上云，其他设备打开即得，合并而非覆盖
- **豆瓣代理**：本机 Python 服务与 Cloudflare Worker 双通道，云端地址已内置，无需逐台配置
- **移动端适配**：手机抽屉导航、边缘滑动手势、长按标记状态
- **本地可用**：下载后双击 `index.html` 即可（数据存本机浏览器）
