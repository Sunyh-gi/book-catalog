云同步 · GitHub

多设备共享同一份书库；快照存于 book-catalog 仓库（library.json），上传需 Token，恢复免费

获取：GitHub → Settings → Developer settings → Fine-grained tokens → Generate：
① Repository access 选「Only select repositories」→ 勾选 book-catalog
② Permissions → Contents → 「Read and write」→ 生成后复制粘贴到这里
③ Token 只存在你的浏览器里，且仅能读写 book-catalog 一个仓库

配置后，本机服务不可用时自动改用云端豆瓣代理（顺序：本机 → 云端）。探测结果见「添加图书」弹层顶部提示。
